# 🌍 Countries Explorer

Aplicação web interativa para consultar informações sobre países utilizando uma API externa.

## 📌 Sobre o projeto

O Countries Explorer foi desenvolvido com HTML, CSS e JavaScript. O usuário pode selecionar um país e visualizar informações como:

* Nome do país
* Nome nativo
* Bandeira
* Capital
* Continente e sub-região
* População
* Área territorial
* Moedas
* Idiomas
* Códigos ISO
* Código telefônico internacional
* Fusos horários
* Fronteiras terrestres
* Links para mapas

As fronteiras também podem ser selecionadas para consultar diretamente outro país.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Fetch API
* Manipulação do DOM
* Async/Await
* API countries.dev

## ▶️ Como executar

1. Clone este repositório:
git clone https://github.com/laraisabelysiq/countries-explorer.git

2. Abra a pasta do projeto no Visual Studio Code.

3. Execute o arquivo `index.html` utilizando o Live Server.

4. Selecione um país no menu para visualizar suas informações.

## 🌐 API utilizada

O projeto utiliza a API countries.dev (https://countries.dev/) para obter os dados dos países.

## 📚 Objetivos de aprendizagem

Este projeto foi desenvolvido para praticar:

* Consumo de APIs externas
* Requisições assíncronas com `fetch`
* Uso de `async/await`
* Manipulação do DOM
* Eventos de seleção e clique
* Tratamento de erros
* Manipulação de dados em formato JSON
* Criação de uma interface responsiva
* Organização e apresentação de dados obtidos de uma API
